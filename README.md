# Discordポイント制度Bot（試作品）

Discordコミュニティで、有益な投稿や回答にポイントを付け、ギフトと交換できるようにするBotの試作品。
Python（discord.py）＋ SQLite。操作はすべてDiscordの中で完結する。

## できること
| 誰が | 操作 | 内容 |
|---|---|---|
| Bot | 自動 | 投稿に3人以上がリアクション → 運営チャンネルに「承認／却下」ボタンつきで通知 |
| メンバー | メッセージを右クリック → アプリ → 「回答として推薦」 | 良い回答を運営に推薦（自分の投稿は推薦できない） |
| 運営 | 承認ボタン | ポイントを付与し、本人にDMで通知（DMを受け取らない人には元のチャンネルでメンション） |
| メンバー | `/points` | 残高と最近の履歴（本人だけに表示） |
| 全員 | `/ranking` | 今月のランキング（交換で使ったポイントは引かない） |
| メンバー | `/gifts`、`/exchange` | ギフト一覧、交換申請（申請した時点でポイントを仮確保） |
| 運営 | 交換の承認・却下ボタン | 承認 → 本人に通知（ギフトは運営が送る）。却下 → ポイントを返却 |
| 運営 | `/admin give` `/admin take` `/admin check` | 手動の付与・減算、メンバーの履歴確認 |
| 運営 | `/admin gift_set` `/admin gift_remove` | ギフトの追加・必要ポイントの変更・一覧から外す |
| 運営 | `/admin log` | 操作ログ（誰がいつ何をしたか） |

## 品質面で気をつけたこと
- **二重付与の防止**：承認ボタンを2回押しても、運営2人が同時に押しても、付与は1回だけ
- **同じ投稿は1回だけ候補になる**：リアクションが増え続けても通知は1回
- **残高のずれ防止**：残高は「ポイントの出入りの記録」の合計で計算する。交換の却下は返却の記録を追加する
- **運営だけが使える**：`/admin` は一般メンバーには表示されない。ボタンも運営以外が押すと断る
- **データが消えない**：SQLiteのファイルに保存するので、再起動しても残る。ボタンも再起動後に押せる
- **操作ログ**：付与・減算・承認・却下・ギフト変更をすべて記録する

## 動かし方
1. [Discord Developer Portal](https://discord.com/developers/applications) でアプリを作り、Botのトークンを発行する
2. OAuth2 → URL Generator で `bot` と `applications.commands` にチェックを入れる。Botの権限は「メッセージを送信」「埋め込みリンク」「メッセージ履歴を読む」を選び、テスト用サーバーに招待する
3. テスト用サーバーに運営用チャンネル（例：#運営-承認）を作る
4. `.env.example` をコピーして `.env` を作り、トークンとIDを入れる（Discordの設定 → 詳細設定 → 開発者モードをオンにすると、右クリックでIDをコピーできる）
5. 起動
   ```
   pip install -r requirements.txt
   python bot.py
   ```
6. テスト：`python test_db.py`（Discordにつながなくても、ポイント処理のテストができる）

※ 試作では人数を集めにくいので、`.env` で `REACTION_THRESHOLD=1` にすると1人のリアクションで試せる（サブアカウントでリアクションする。投稿者本人のリアクションは数えない）。
